# 🧮 Calculator

> A beautiful, interactive calculator built with HTML, CSS, and JavaScript

## ✨ Features

- 🎨 **Modern UI Design** - Clean gradient background with smooth animations
- ⚡ **Fast Performance** - Instant calculations with no delays
- 🔢 **Full Functionality** - Addition, subtraction, multiplication, division, and modulo operations
- 💯 **Decimal Support** - Work with decimal numbers seamlessly
- 🟢 **Error Handling** - Safe division by zero handling
- 📱 **Responsive Design** - Works beautifully on all screen sizes
- ✅ **User-Friendly** - Intuitive button layout and clear display

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Firefox, Safari, Edge)
- No installation needed!

### Installation

1. Clone the repository:
```bash
git clone https://github.com/parnika-sa/calculator.git
cd calculator
```

2. Open `calculator.html` in your web browser:
   - Simply double-click the `calculator.html` file, or
   - Right-click and select "Open with" your preferred browser

## 📊 Supported Operations

| Operation | Symbol | Example |
|-----------|--------|---------|
| Addition | + | 5 + 3 = 8 |
| Subtraction | − | 10 − 4 = 6 |
| Multiplication | × | 6 × 7 = 42 |
| Division | / | 20 / 4 = 5 |
| Modulo | % | 10 % 3 = 1 |

## 🎯 How to Use

1. **Click numbers** to input them into the calculator
2. **Select an operation** (+, −, ×, ÷, %)
3. **Enter another number**
4. **Press =** to see the result
5. **Press AC** to clear and start over

## 🌈 Design Highlights

- **Color Scheme**: Purple gradient background (#667eea → #764ba2)
- **Display**: Terminal-style green text on dark background

  - Number buttons: Light gray (#ecf0f1)

## 🐛 Known Limitations

- No history feature
- No keyboard input support (button clicks only)
- Limited to basic arithmetic operations
